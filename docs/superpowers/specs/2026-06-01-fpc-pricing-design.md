# 모심 FPC — 가격 정책 & 포함 범위 (확정)

> 작성일: 2026-06-01 · 상태: **확정 (founder 승인)** · *living doc — 바뀌면 이 문서부터 수정*
> 북극성: `2026-06-01-mosim-product-definition.md` · 결제 토대: [[project_payment_gate]]
> FPC = **Full Private Concierge.** 이 문서는 모심이 *무엇을 청구하고 / 무엇을 함께 챙기는지*의 단일 기준.

## 1. 핵심 원칙 — 서비스와 청구를 분리한다

- **서비스 범위(FPC) = 다 해드린다.** 예약·통역·전용차·동행·24시간. 'full'을 만드는 것.
- **청구 범위(Fee) = 모심이 *운영하는* 것만.** 큰 원가(의료·호텔·항공)는 **모심 청구서에 안 들어감** — 손님이 vendor에 **직접** 결제(단, 모심이 다 주선·동행).
- **결제를 분리해도 서비스는 안 줄어든다.** 호텔을 손님 카드로 내도, 고르고·예약하고·체크인에 함께 서 있는 건 모심.

**🔒 재무 하드룰 — 원가를 모심 PG로 통과시키지 않는다.**
의료비 $50,000을 모심 PayPal로 받아 병원에 전달하면 PG 수수료 ~3%(=$1,500)를 *한 푼도 안 남기는 돈에* 손실. 또 손님은 거액 lump sum 부담. → **vendor 직접 결제가 감성이자 재무적 정답.**

## 2. 포함 / 함께 챙김 (두 버킷)

표현 원칙: 차가운 *"Not included"* 금지. 따뜻하게 **"What we'll also take care of."**

| 🟢 **What's included** *(모심 fee — 모심이 직접 *운영*)* | 🤝 **What we'll also take care of** *(손님이 직접 결제, 모심이 주선·동행)* |
|---|---|
| 맞춤 설계 · AI 일정 | 의료비(병원·시술) |
| 병원 매칭 · 예약 · 일정 조율 | 호텔 *(등급은 손님 선택)* |
| 전담 통역 (모든 진료·서류) | 항공 |
| 전담 컨시어지 동행/온콜 · 24시간 | |
| **전용차 · 기사 (전 일정)** | |
| **일상 식사 (일정 중)** — 경계는 §3 | |
| 공항 영접·배웅 · 회복 지원 | |
| 결제 안전 안내 (어디·얼마·어떻게) | |

**경계의 원칙:** 모심이 *운영하는 경험*(차·통역·동행·끼니·일정) = fee 안. 손님이 *취향껏 고르는 큰 항목*(시술·호텔 등급·항공) = 직접 결제 + 모심 동행. → 차·식사는 포함, 호텔은 직접인 *이유*(호텔은 등급 따라 값 차이 크고 취향 선택).

## 3. 식사 경계

- ✅ 포함: **일정 중 일상 식사** — 하루 세 끼, 컨시어지 안내 + 모심 커버(일당에 반영).
- ❌ 개인: 특별한 고급 만찬 · 술 · 개인 간식 · 쇼핑.
- 이유: 식사는 날짜로 깔끔히 안 떨어짐 → 경계를 둬야 원가 예측 가능. (식사는 금액이 작아 PG 부담은 경미.)

## 4. Fee 구조 — 기간 기반

- Fee는 *노동값*이 아니라 *날짜에 비례하는 운영 원가(기사·통역·동행·식대) + 마진*을 둘 다 덮어야 한다 → **기간이 길수록 fee↑.**
- 공식 방향(투명 공개):
  > **기본 fee + (일수 × 일당) + (추가 동행 1인당 소액)**
- 플래너 끝에서 **즉석 견적**으로 계산해 보여줌 — **회원가입 불필요.**
- ⚠️ **실제 숫자(일당 등)는 미정** — 진짜 기사·통역 단가 데이터 필요. **$0 단계라 보류**, 구조만 확정. [[zero-cost-build-phase]]
- 이전 *"$1,200 × 인원수"* 모델은 이 기간 기반으로 **대체됨.**

## 5. 투명성 (반-인질극)

- "질문 잔뜩 → 가입해야 가격 공개" **금지.** 가격은 **가입 없이 명확하게.**
- 플래너 결과 화면에서 한 번에:
  1. **AI 일정**
  2. **모심 fee — 명확** ("이게 저희가 받는 전부입니다")
  3. **의료비 추정 범위 + 미국 대비 절감** (예: 한국 $A–$B / 미국 $C, *최종은 병원이 확정*)
  4. 강요 아닌 **초대** ("이대로 진짜 가볼까요?") — 연락처는 가둬서가 아니라 신뢰 후 자발적으로.

## 6. 결제 메커닉

- 모심 fee: PayPal(한국 법인) · **분할 결제 가능**(기존 `pay.html`/`payment_groups`) → lump sum 부담↓.
- vendor 비용(의료·호텔·항공): 손님이 직접 결제, 모심이 *"어디·얼마·어떻게"* 안전하게 안내(돈은 안 만짐).

## 7. 아직 안 정함 (나중)

- 결과 화면(투명 견적) 상세 UI — **다음 디테일.**
- 의료비 추정 범위 데이터 출처(병원 협의 / 공개 자료).
